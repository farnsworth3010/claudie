# Claudie

**Управляй сессиями, а не нянчись с ними, глядя, как они работают.**

[English](README.md) · **Русский**

Пиксельные Клоды на экране Mac, по одному на каждую запущенную сессию Claude Code. Каждый показывает, чем занята его сессия: печатает, запускает команду, ищет, ждёт твоего разрешения, задаёт вопрос, закончил или давно уснул. Сабагенты появляются мини-Клодами вокруг Клода своей сессии.

> **Статус: ранняя разработка.** Часть для Claude Code ставится плагином; приложение для Mac пока собирается из исходников.

> Claudie — неофициальный фанатский проект, не связанный с Anthropic и не одобренный ею. Claude и Clawd принадлежат Anthropic.

Это не всё: в приложении анимаций больше, и все их показывает [страница настроек](#настройки).

Сабагенты получают свой облик по имени: исследователь, ревьюер, безопасник, планировщик, тестировщик, отладчик, писатель, дизайнер, исполнитель, рефакторщик или помощник для всех остальных. В режиме плана Клод самой сессии надевает каску планировщика. Вокруг Клода сессии помещается до шести мини-Клодов; пиксельное +N над последним считает остальных.

## Как пользоваться
- **Наведи** на Клода, чтобы увидеть его проект, чем он занят, насколько заполнен контекст и какие у него сабагенты.
- **Перетащи** группу куда угодно: она идёт следом, врезается в края экрана и запоминает, где ты её оставил.
- **Кликни**, чтобы ткнуть Клода. Три клика подряд — и он пищит.
- **Ctrl + колесо** над Клодом меняет размер.
- **Правый клик** по Клоду открывает [страницу настроек](#настройки).
- Всё остальное на экране остаётся кликабельным: мышь ловят только нарисованные пиксели.

## Как это устроено
```
машина с Claude Code                                              Mac
Claude Code ─хуки──► claudie-daemon ─события (127.0.0.1:47321)─► Claudie.app
            ─файлы транскриптов──┘
```
- **Хуки.** Claude Code сообщает демону о каждом событии через свои хуки.
- **Демон** выясняет, что делает каждая сессия. Отказ в разрешении и Esc хуков не оставляют, поэтому демон ещё читает транскрипт каждой сессии; оттуда же он узнаёт, насколько заполнен контекст. Он проверяет, жив ли процесс каждой сессии, и сохраняет сессии между перезапусками.
- **Приложение на Mac** рисует то, что сообщает демон, в прозрачном окне поверх всех остальных.
- **Страницу настроек** раздаёт сам демон, поэтому она одинаково работает с любого компьютера, который до него достаёт.

| Часть | Язык | Где |
|---|---|---|
| Логика сессий, анимации, раскладка | TypeScript | `backend/core` |
| Демон | Go (выполняет TypeScript в [goja](https://github.com/dop251/goja)) | `backend/daemon` |
| Хук | POSIX sh | `backend/plugin` |
| Приложение для Mac | Swift (выполняет TypeScript в JavaScriptCore) | `frontends/macos` |
| Страница настроек | TypeScript, [Angular](https://angular.dev) | `frontends/web` |

Демон, приложение и страница настроек выполняют один и тот же TypeScript, поэтому логика живёт в одном месте и тестируется один раз.

## Установка и запуск
**Понадобится:** Claude Code на macOS или Linux и Mac с macOS 14 или новее для приложения.

1. **Установи плагин** в Claude Code:
   ```
   /plugin marketplace add farnsworth3010/claudie
   /plugin install claudie@claudie
   ```
   Больше на стороне Claude Code ничего настраивать не нужно. Первая сессия после установки скачивает демон для твоей платформы из релизов этого репозитория, проверяет контрольную сумму и запускает его в фоне; следующие сессии находят его уже работающим.
2. **Собери и запусти приложение** на Mac. Нужны Xcode Command Line Tools (`xcode-select --install`), а для сборки сцены — [Node.js](https://nodejs.org) 25 и [pnpm](https://pnpm.io):
   ```sh
   git clone https://github.com/farnsworth3010/claudie.git && cd claudie
   pnpm install && pnpm build
   cd frontends/macos && swift run
   ```
   Если Claude Code работает на другой машине, приложение всё равно обращается к `127.0.0.1:47321` на Mac: пробрось этот порт на машину с демоном, например `ssh -L 47321:127.0.0.1:47321 <host>`.

Демон пишет лог в `~/.local/state/claudie/daemon.log`. Чтобы запускать его из исходников, собери `(cd backend/daemon && go build -o bin/claudie-daemon ./src)` (нужны [Go](https://go.dev) 1.27 и сначала `pnpm build`) и запусти `backend/daemon/bin/claudie-daemon` до начала сессий.

**Обновление:** `claude plugin update claudie@claudie` или `/plugin` в сессии. Следующая сессия сама запустит новый демон вместо старого.

### Демо
`tools/demo.sh` показывает Клодов без настоящих сессий: отправляет демону выдуманные сессии во всех состояниях (печатает, команда сабагентов, ждёт разрешения и вопрос, жар от полного контекста, режим плана, коммит) и гоняет их, пока не нажмёшь Ctrl+C, — тогда они уходят. Всё запускается на Mac из клона; кроме того, что нужно приложению, понадобится [Go](https://go.dev) 1.27:
```sh
pnpm install && pnpm build
(cd backend/daemon && go build -o bin/claudie-daemon ./src)
backend/daemon/bin/claudie-daemon start   # демон, в фоне
(cd frontends/macos && swift run)         # приложение; оставь его работать и продолжай во втором терминале
./tools/demo.sh
```
Если демон уже работает (его запустил плагин или ты пробросил его порт), шаги с Go и демоном не нужны: `./tools/demo.sh` достаточно достучаться до `127.0.0.1:47321`. Запущенный тобой демон потом останови командой `curl -X POST -H 'content-type: application/json' -d '{}' http://127.0.0.1:47321/quit`.

На [странице настроек](#настройки) тоже есть симулятор: кнопки, которые заводят выдуманные сессии и проводят их по всем состояниям шаг за шагом.

### Настройки
**Кликни правой кнопкой по Клоду** или открой в браузере [http://127.0.0.1:47321/](http://127.0.0.1:47321/): это страница настроек, её раздаёт демон. На ней:
- настройки, они применяются сразу ко всем оверлеям;
- живое превью твоих сессий, нарисованное тем же кодом, что и в приложении: на Клодов можно навести, перетащить их, ткнуть и поменять размер;
- симулятор выдуманных сессий: они видны и на Mac и уходят, когда закрываешь страницу;
- галерея всех анимаций, скинов сабагентов, стадий болезни, цветов и размеров.

Демон хранит настройки в `~/.config/claudie/settings.json` и передаёт приложению:

| Настройка | По умолчанию | Что делает |
|---|---|---|
| `size` | 4 | Экранных точек на пиксель рисунка, от 2 до 12 (меняется Ctrl + колесо) |
| `miniSize` | 0.5 | Размер мини-Клодов сабагентов относительно Клода сессии, от 0.3 до 1; масштабируются вместе с ним |
| `opacity` | 1 | От 0.2 до 1 |
| `pace` | 1 | Скорость анимаций, от 0.5 до 1.5 |
| `overFullscreen` | false | Показывать поверх полноэкранных приложений |
| `clickThrough` | false | Клики проходят сквозь Клодов к тому, что под ними; с зажатым ⌥ Option их можно тащить, тыкать и открывать настройки (macOS) |
| `overDock` | true | Клоды могут стоять на Доке; если выключено, держатся вне его области (macOS) |
| `overMenuBar` | false | Клоды могут заходить на строку меню (macOS) |
| `gaze` | true | Глаза следят за указателем |
| `antics` | true | Дурачится, когда диалог долго ждёт ответа |
| `neglect` | true | Паутина, цветок, снег и кости при долгом простое |
| `stroll` | false | В простое медленно прохаживается вместо сна, паутины и скелета |
| `anywhere` | false | С `wander` и без гравитации ходит по всему экрану, стоя, а не ползает по краям |
| `sleepAfter` | 45 | Секунд простоя до зевка и сна, от 10 до 600 |
| `neglectAfter` | 300 | Секунд простоя до паутины, от 60 до 3600; цветок, снег и кости — в той же пропорции |
| `patience` | 30 | Секунд ожидания диалога до выходок, от 5 до 300 |
| `inertia` | false | Брошенная группа летит дальше, замедляется и отскакивает от краёв экрана |
| `gravity` | false | Отпущенная группа падает на нижний край экрана и стоит там |
| `wander` | false | Сам ходит туда-сюда и ползает по краям экрана, повернувшись к ним ногами; с гравитацией только по нижнему краю. Пока сессия ждёт тебя, стоит на месте. Без гравитации, если поднести к краю при перетаскивании, прилипает к нему, поворачивается и ползёт дальше оттуда, где отпустил |

Или поменять из терминала:
```sh
curl -X POST -H 'content-type: application/json' -d '{"opacity":0.8}' http://127.0.0.1:47321/settings
```

## Удаление
1. **Удали плагин** в Claude Code; заодно удалится скачанный им бинарник демона:
   ```
   /plugin uninstall claudie@claudie
   /plugin marketplace remove claudie
   ```
2. **Останови демон:**
   ```sh
   curl -X POST -H 'content-type: application/json' -d '{}' http://127.0.0.1:47321/quit
   ```
3. **Удали его файлы** (сессии, лог, настройки):
   ```sh
   rm -rf ~/.local/state/claudie ~/.config/claudie
   ```
4. **На Mac** останови приложение (Ctrl+C там, где идёт `swift run`), сотри сохранённую позицию командой `defaults delete Claudie` и удали клон.

## Разработка
`pnpm check` запускает всё: линтер и форматтер Biome, проверку типов TypeScript, тесты TypeScript, сборку, затем `gofmt`, `go vet`, тесты Go и `govulncheck`. Сообщения коммитов следуют Conventional Commits, их проверяет commitlint. Релиз — это тег `vX.Y.Z`, совпадающий с `version` в `backend/plugin/.claude-plugin/plugin.json`: CI собирает демон под все платформы и публикует его. Структура проекта и правила кода — в [CLAUDE.md](CLAUDE.md).

## Как здесь используется ИИ
Claudie делается вместе с Claude Code, агентом для программирования от Anthropic. Порядок работы записан в [CLAUDE.md](CLAUDE.md); агент читает его в начале каждой сессии.
- **Решает мейнтейнер, агент пишет и объясняет.** Архитектура, выбор языков, модель состояний и каждый компромисс — решения мейнтейнера. Агент пишет большую часть кода маленькими шагами, объясняет каждый файл и решение и ждёт одобрения перед следующим шагом.
- **Факты из экспериментов, а не догадок.** Как Claude Code на самом деле сообщает о разрешениях, Esc, сабагентах и сжатии контекста, выяснено на настоящих сессиях с записью их событий; логика состояний тестируется на этих записях.
- **Параллельные агенты и отдельное ревью.** Независимые части (анимации, Go-демон, Swift-приложение) часто пишут параллельные сабагенты по заранее согласованным интерфейсам, а отдельный агент-ревьюер ищет баги до того, как работа считается законченной. Перенесённые анимации сверяются попиксельно, миллион кадров за раз.
- **Последнее слово за людьми.** Агент работает на Linux, поэтому Swift-приложение собирает и запускает на Mac мейнтейнер и сообщает о результате; все коммиты делает мейнтейнер.
